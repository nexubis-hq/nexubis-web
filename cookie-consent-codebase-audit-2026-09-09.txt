NEXUBIS COOKIE CONSENT CODEBASE AUDIT
Date: 2026-09-09

The current app loads Clarity and Meta site-wide without a visitor consent check, including /audit. Meta also writes three first-party tracking cookies and sends server-side conversion events. GA exists in the legacy Webflow export, but no active GA/GTM integration was found in the Next.js app.

This is a static code inventory, including application source, configuration, scripts, public assets, legacy exports, relevant installed dependencies, and generated HTML. Vendor-controlled cookies are identified separately: their actual presence and expiry cannot be established conclusively from this repository alone. No application code was changed during the audit.

All file references below are relative to the project root. Line numbers refer to the code reviewed on the audit date.

Consent terminology follows the EU distinction between necessary storage and non-essential tracking. The cookie rule comes from ePrivacy legislation alongside GDPR; POPIA separately permits several processing grounds under section 11, so "all non-essential cookies require consent under POPIA" is not an exact statement of that Act.
Sources:
- CNIL cookie guidance: https://www.cnil.fr/fr/cookies-et-autres-traceurs/que-dit-la-loi
- POPIA, section 11: https://www.justice.gov.za/legislation/acts/2013-004.pdf

4.3 Meta Conversions API - non-necessary server-side tracking

- lib/meta/track.ts:66
  Ensures tracking cookies exist, calls the browser Pixel and posts matching data to /api/meta-event. No consent check.
- app/api/meta-event/route.ts:95
  Enriches events with IP address/user agent and forwards them. Host and internal-email filtering exist; no visitor-consent validation.
- lib/meta/capi.ts:110
  Sends to https://graph.facebook.com/v19.0/<pixelId>/events. Operates when META_CAPI_TOKEN is configured.
- lib/cal-webhook/handler.ts:255
  Sends Schedule after an eligible BOOKING_CREATED webhook. Independent of the browser script; no browser-consent lookup found.

CAPI transmits event details, source URL and available identifiers. Email/first name are hashed server-side; _fbc, _fbp and external ID are sent un-hashed. IP/user agent accompany browser-relayed events.

Event locations:
- Global PageView: components/MetaPixel.tsx.
- /audit: AuditStart, Lead, AuditComplete in components/scorecard/flow/ScorecardFlow.tsx:147.
- Report views, excluding the demo: components/scorecard/report/ReportViewTracker.tsx:19.
- Report booking clicks: SessionUnlockClick and AuditBookClick in components/scorecard/report/BookCallButton.tsx:47.
- Successful contact submission: Contact in components/ContactTabs.tsx:197.
- Confirmed bookings: Webhook Schedule, as above.
