BLOG RICH-TEXT LIST PARITY FIX

Scope

Fixed the Blog rich-text list parity issue for the reusable /post/[slug]
template.

No Sanity setup was started.
No additional Blog posts were migrated.
No Lottie, showreel, TOC, article data, header, footer, route or metadata
changes were made.

Root Cause

The sanitizer was not the issue. The fixture body HTML still preserved semantic:
- ul
- ol
- li

The root cause was the global reset in app/globals.css:
- ul { list-style: none; }

The Blog rich-text scoped CSS restored list indentation but did not restore
semantic marker styles, so list items rendered without visible bullets.

Files Changed

- components/blog/BlogPost.module.css
- lib/blog/post-fixtures.test.ts

CSS Correction

Restored scoped Blog rich-text list styling:
- unordered lists use list-style-type: disc
- ordered lists use list-style-type: decimal
- list-style-position: outside
- list item display: list-item
- marker colour: var(--body)
- marker size: 1rem
- nested lists keep semantic indentation and spacing

Recovered Live Measurements

Measured live Webflow list styling:
- list-style-type: disc
- list-style-position: outside
- left padding: 35.2px
- list margin-bottom: 16px
- list item line-height: 25.6px
- list item font-size: 16px
- list item margin-bottom: 4.8px
- marker colour: rgb(90, 90, 90)
